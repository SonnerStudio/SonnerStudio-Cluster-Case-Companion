🚀 Uniting Apple Silicon Macs: SonnerStudio Cluster-Case-Companion (SS-CCC) v1.6.44

Why rent expensive datacenter GPUs when your existing Macs can work together as one local or global AI cluster?

That is the exact purpose of SS-CCC: Built natively in SwiftUI for macOS, this open-source app links any Apple Silicon Macs (M1 through M12+) over Thunderbolt 3/4/5, RDMA (JACCL), or encrypted Internet WAN bridges (Tailscale, WireGuard, QUIC/Iroh) into one unified memory pool for local LLMs (MLX, oMLX, Ollama, llama.cpp). Sensitive code and documents stay 100% under your own control — with zero cloud fees.

🛠️ Current Development Status (v1.6.44 · 25/25 automated tests passing):
✅ 11 modules in one studio: Cluster Overview, Device Telemetry (CPU, GPU & Neural Engine cores), Model Studio, Network & RDMA, Internet Cluster with live chat & Audio-Party, Auto-Setup & 4-state Readiness Check
✅ Multi-Model Mode (MMM): Run multiple models in parallel, via Mixture-of-Agents, or Speculative Decoding over :8000/v1 simultaneously for Cursor, VS Code, Xcode, OpenCode, Hermes Agent & Antigravity
✅ 6-Tab Scientific Research Lab: Log-Log Roofline, WAN scaling (N=1..128), KV memory analysis, Energy/CO₂ (J/token, EDP), reproducible trials (CI₉₅, LaTeX/BibTeX) & history recording
✅ Menu Bar Background Service (⌘⇧M) & new Solaris Dock Icon: When minimized, SS-CCC moves into the top macOS menu bar right next to Ollama with live telemetry indicators and 1-click API endpoints, silently serving IDEs & agents in the background
